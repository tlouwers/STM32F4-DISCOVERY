# STM32F4 Reference Documents

This folder contains reference documents for the STM32F407G-DISC1 board and MCU.

## Documents

- `stm32f407vg-datasheet.pdf` — STM32F407VG device datasheet
- `rm0090-reference-manual.pdf` — STM32F4 reference manual (registers, peripherals)
- `pm0214-programming-manual.pdf` — PM0214: STM32 Cortex-M4 programming manual
- `es0182-errata.pdf` — STM32F4 errata sheet (silicon bugs and workarounds)
- `discovery-kit.pdf` — Board quick reference / brochure
- `um1472-discovery-board.pdf` — UM1472: Discovery board user manual (schematic, jumpers)
- `um1467-software-environment.pdf` — UM1467: getting started with software/firmware environments
- `um2052-getting-started-tools.pdf` — UM2052: discovery kits and development tools
- `an3155-usart-bootloader.pdf` — AN3155: USART protocol used by the STM32 bootloader
- `an3364-migration.pdf` — AN3364: migration and compatibility guidelines
- `an3990-upgrading-firmware.pdf` — AN3990: upgrading Discovery firmware with USB key
- `an4031-dma.pdf` — AN4031: DMA controller usage
- `an4899-gpio-lowpower.pdf` — AN4899: GPIO and low-power considerations
- `tn1235-stlink.pdf` — TN1235: ST-Link overview
